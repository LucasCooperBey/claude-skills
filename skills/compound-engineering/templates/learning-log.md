# LEARNINGS.md

Persistent learning log for compound engineering cycles. Append each entry — never overwrite.

---

## Template for Each Entry

```markdown
## [YYYY-MM-DD] — [What was improved]

### What worked
- [technique/approach that succeeded]

### What didn't
- [approach that failed or was harder than expected]

### Patterns discovered
- [new pattern worth remembering for future work]

### Avoid next time
- [anti-pattern or mistake to not repeat]

### Key decisions
- [important choices made and why]

### Dependencies/tools
- [new tools discovered or dependency insights]

### Time spent
- Analysis: [X min]
- Planning: [X min]
- Execution: [X min]
- Total: [X min]
```

---

## How This File Is Used

1. **Read at start of every compound cycle** — Analysis phase checks for relevant past learnings
2. **Appended at end of every cycle** — Learning phase adds new entry
3. **Referenced during planning** — Avoid repeating mistakes
4. **Informs CLAUDE.md updates** — When patterns are project-wide, promote to CLAUDE.md

## Location

This file lives at the **project root** (next to CLAUDE.md) so it persists across sessions and branches.
