100,000 ft: for anyone

What you do first is read README.md. It lists 53 skills and gives the install commands: clone the repo, then copy a folder with cp -R into ~/.claude/skills/. Each of those 53 folders under skills/ is one skill, and each contains a SKILL.md. After a restart, Claude Code uses the skill when a task matches the description in that file.

Why a normal person should care

You keep the method in a folder instead of in a chat. The next session can follow the same steps. The license files show which folders are this repo's own MIT work and which folders keep an upstream license.

50,000 ft: strategic

The bigger goal is a method Claude Code can load again from a folder, with the credit and the license written beside it. README.md is the index, skills/ holds the 53 methods, and LICENSE, THIRD_PARTY_NOTICES.md, and seven LICENSE.txt files hold the rights. AGENTS.md tells an agent to inspect skills/ first. The picture at 100,000 ft uses skills/pp2p because README.md line 69 copies that folder first. Any other folder under skills/ copies the same way.

Problem-class it solves

The end state is one folder under ~/.claude/skills/ whose SKILL.md Claude Code can follow. README.md Install is the mechanism: clone this repo, then cp -R a skill folder.

The next session has the skill file after that folder is copied into ~/.claude/skills/. README.md line 74 says the skill then activates when the task matches its description, or you invoke it.

Use a folder from this repo when you want a Claude Code skill. README.md calls the library no-secrets, and it calls the contents methodology.

README.md says some skills were extracted from a private setup and some were adapted or inspired by public work, then scrubbed of personal paths, project names, and infrastructure. That public work is named in README.md Credits, under Adapted or copied, Inspired by, and Copies whose upstream carries no license, and in THIRD_PARTY_NOTICES.md, including anthropics/skills, openai/skills, and obra/superpowers.

The files behind this explanation are README.md, AGENTS.md, LICENSE, THIRD_PARTY_NOTICES.md, the seven LICENSE.txt files, and the SKILL.md in each folder under skills/. The repo has no dated writeup of a first instance growing into a hardened standard.

30,000 ft: the pipeline / technical shape

Five handoffs, each one a real file or the copy README.md tells you to make. The SKILL.md check is the gate. The license files are the guard. The copy is the human step.
